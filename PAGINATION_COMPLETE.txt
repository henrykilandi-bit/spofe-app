┌─────────────────────────────────────────────────────────────────────────────┐
│                       📊 ENDPOINTS DISPONIBLES                              │
└─────────────────────────────────────────────────────────────────────────────┘

  GET /api/secure-journal/entries?page=1&limit=50
  │
  ├─ Paramètres: page, limit, cursor, startDate, endDate, status, reference
  ├─ Response: data[], pagination{}, filters{}, metadata{}
  └─ Cache: Redis (5 min)

  GET /api/secure-journal/entries/:id
  │
  ├─ Récupère détail d'une entrée
  ├─ Inclut les lignes
  └─ Pas de pagination (detail par ID)

  GET /api/secure-journal/search?q=term&page=1&limit=20
  │
  ├─ Recherche avec pagination
  ├─ Min: 2 chars, Max: 100 chars
  └─ Limite résultats: 50/page max

  GET /api/secure-journal/export?format=csv&startDate=2024-01-01
  │
  ├─ Export CSV ou JSON
  ├─ Max 10,000 rows
  ├─ Max 365 jours
  └─ Download directement

  GET /api/secure-journal/stats  (Admin/Manager only)
  │
  ├─ Statistiques pagination en temps réel
  ├─ Cache hit rate, slow queries, patterns
  └─ Health status complet

  POST /api/secure-journal/stats/reset  (Admin only)
  │
  └─ Réinitialiser toutes les statistiques

  GET /api/secure-journal/documentation
  │
  └─ Documentation API complète

## 🗂️ Scripts Overview

### **Core Automation Scripts**

#### `scripts/auto-fix.js` (180 lines)
**Main orchestrator script**
- Validates environment
- Coordinates 5 phases
- Generates reports
- Supports dry-run mode

**CLI Options:**
```bash
node auto-fix.js                    # Full execution
node auto-fix.js --dry-run          # Simulation mode
node auto-fix.js --skip-package     # Skip package fixes
node auto-fix.js --skip-db          # Skip DB validation
node auto-fix.js --skip-report      # Skip report generation
node auto-fix.js --verbose          # Verbose logging
```

#### `scripts/modules/package-fixer.js` (165 lines)
- Fixes root, backend, frontend package.json
- Removes duplicates
- Harmonizes versions
- Installs dependencies

#### `scripts/modules/database-validator.js` (140 lines)
- Connects to MySQL
- Validates table structure
- Checks FK constraints
- Calculates conformity %

#### `scripts/modules/test-fixer.js` (195 lines)
- Adds window.matchMedia mock
- Converts Jest imports to Vitest
- Fixes empty test files
- Creates Sequelize mocks

#### `scripts/modules/report-generator.js` (280 lines)
- Generates 4 markdown reports
- Tracks metrics
- Provides recommendations
- Creates action plan

#### `scripts/utils/logger.js` (65 lines)
- Colored console output
- Progress indicators
- Formatted sections
- Timestamp tracking

## 📊 Test Failure Analysis Guide

### **Using RAPPORT_ANALYSE_TESTS_DETAILLE.md**

**To find a specific test:**
1. Use Ctrl+F to search for test name
2. Find "### TEST #X" section
3. Read the 9-point analysis:
   - 1) Name
   - 2) Objective
   - 3) Importance (🔴/🟡/🟠 priority)
   - 4) Status (✅/❌/⏸️)
   - 5) Root cause
   - 6) Blocking files
   - 7) Solution
   - 8) Conclusion
   - 9) Recommendation

**Priority Levels:**
- 🔴 **CRITICAL** - Blocks functionality
- 🟠 **HIGH** - Affects features
- 🟡 **MEDIUM** - UI/UX issues
- 🟢 **LOW** - Minor improvements

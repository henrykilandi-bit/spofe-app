## 🚀 DEVOPS

### Configure CI/CD

Guardian Level 4 check is now required for merge:

```yaml
name: SILC Guardian Check
on: [pull_request, push]
jobs:
  guardian:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - run: cd cascade && npm ci
      - run: cd cascade && npm run guardian:check
```

Set branch protection rule: `SILC Guardian Check` ✅ required

## 📊 THE 8 RULES (I1-I8)

These are IMPOSSIBLE TO BYPASS:

| # | Rule |
|---|------|
| I1 | One active role per user-context max |
| I2 | Every role must have a context |
| I3 | No state change without decision |
| I4 | Audit recorded after decision (never before) |
| I5 | Authorization ≠ Ability |
| I6 | Revocation is permanent (Transfer only) |
| I7 | Every role in audit trail |
| I8 | Audit trail immutable |

Breaking any = **Merge blocked.**

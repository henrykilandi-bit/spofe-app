  ↓
  [Phase 1: Pagination-Protection Middleware]
  ├─ Validate: page=1, limit=50 ✓
  ├─ Rate limit: 100 req/min ✓
  └─ Pattern detection: Normal ✓
  ↓
  [Phase 2: Cache Middleware]
  ├─ Generate key: cache:comp:1:entries:page:1:limit:50
  ├─ Try Redis: Hit! ✓
  └─ Return cached response (5-10ms)
  ↓
  Response:
  {
    data: [...],
    X-Cache: HIT,
    X-Pagination: { page: 1, limit: 50, total: 5000 },
    X-Cache-Age: 45s
  }

Or if Cache Miss:
  ↓
  [Phase 1: Query Optimization]
  ├─ Batch loading with IN clause
  ├─ Execute 3 queries instead of 51
  └─ Get results (100-200ms)
  ↓
  [Phase 2: Cache Storage]
  ├─ Store in Redis (SETEX 300s)
  ├─ Store in memory fallback
  └─ Return response
  ↓
  X-Cache: MISS (but now cached for next request)

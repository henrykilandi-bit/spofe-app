# Module budget

## Statut

Socle fiable oriente guardian et lecture systeme.

## Ce qui est vrai aujourd'hui

- Le module compile et ses tests locaux sont branches.
- Il dispose d'un guardian et de scenarios systeme de lecture deja exploitables.
- Le module couvre un premier socle de consultation des objectifs, de timeline et d'alertes budgetaires.

## Ce que le module ne pretend pas encore etre

- un module budget complet sur tout le cycle de pilotage
- une implementation exhaustive des calculs et arbitrages budgetaires
- un produit finalise sur l'ensemble des usages budgetaires

## Scripts

- `npm run build` : verification TypeScript du module.
- `npm test` : validation Jest du module.

## Prochaine etape utile

- approfondir les cas metier budgetaires
- expliciter les limites du perimetre actuellement expose
- renforcer la documentation des scenarios couverts

🎯 UTILISATION IMMÉDIATE
═════════════════════════════════════════════════════════════════════════════

  1. Aucune installation supplémentaire
  2. Lancez le développement: npm run dev
  3. Allez sur http://localhost:5173/login
  4. Les identifiants de test sont pré-remplis
  5. Cliquez "Se connecter"
  6. Entrez "123456" pour le code 2FA
  7. Redirection automatique vers le dashboard

  ➜ C'est prêt! 🎉

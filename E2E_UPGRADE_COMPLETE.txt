🚀 DÉMARRAGE RAPIDE
═══════════════════════════════════════════════════════════════════════════

Première exécution (5-10 minutes):

  1. Validation système:
     cd cascade && bash e2e/SYNC_E2E.sh

  2. Démarrer serveur:
     npm run start:test

  3. Dans un autre terminal - lancer tests:
     npm run e2e

  4. Voir résultats:
     npm run e2e:report

Commandes essentielles:
  npm run e2e                   # Tous les tests
  npm run e2e:accounting        # Tests comptables
  npm run e2e:security          # Tests sécurité base
  npm run e2e:audit             # Tests sécurité avancés ✨
  npm run e2e:performance       # Tests performance ✨
  npm run e2e:critical          # Tests critiques
  npm run e2e:ui                # Mode UI interactif
  npm run e2e:debug             # Mode debug
  npm run e2e:report            # Voir rapports

💬 QUESTIONS FRÉQUENTES
═══════════════════════════════════════════════════════════════════════════════

Q: Dois-je modifier les modèles Sequelize?
R: NON. Les modèles restent en snake_case (DB standard).
   Les DTOs font la transformation.

Q: Dois-je créer un DTO pour chaque endpoint?
R: NON. Une entité = 1 DTO (réutilisable dans plusieurs endpoints).

Q: Les DTOs existent déjà, j'ai trouvé des versions anciennes?
R: OUI, elles sont dans cascade/src/dto/.
   Elles ont été mises à jour et améliorées pour SILC v1.0.

Q: Comment gérer un champ qui doit être conditionnel?
R: Le DTO peut avoir logique de null-check, mais pas de logique métier.
   Si besoin de logique, utiliser un service et l'appeler dans le controller.

Q: Qu'est-ce que je fais pour un vieux endpoint qui casse?
R: Appliquer SILC progressivement endpoint par endpoint.
   Pas de big-bang, migrations graduelles OK.

📞 SUPPORT TECHNIQUE
═══════════════════════════════════════════════════════════════════════════════

ERREUR: "userDto is not defined"
FIX: import { userDto } from '../dto/index.js';

ERREUR: "user_id undefined" (en frontend)
FIX: Utiliser mapper! mapUser(response.data) → user.companyId

ERREUR: "timestamp missing" (dans API)
FIX: Ajouter dans meta: { timestamp: new Date().toISOString() }

ERREUR: Champ n'existe pas dans DTO
FIX: 1) Créer/modifier DTO
     2) Ajouter export dans cascade/src/dto/index.js
     3) Tester

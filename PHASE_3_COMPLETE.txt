## 🚀 Déploiement

### Installation

```bash
# 1. Dépendances
npm install

# 2. Générer diagrammes
npm run docs:generate-diagrams

# 3. Vérifier localement
npm run docs:serve
npm run e2e:ui
```

### Commandes Essentielles

```bash
# Documentation
npm run docs:generate-diagrams     # Générer
npm run docs:watch                 # Watch mode
npm run docs:serve                 # Serveur local

# Tests E2E
npm run e2e                        # Tous les tests
npm run e2e:accounting             # Tests accounting
npm run e2e:security               # Tests sécurité
npm run e2e:ui                     # Interface graphique
npm run e2e:debug                  # Mode debug

# CI/CD
npm run e2e:report                 # Voir rapports
```

## 📝 Notes de Maintenance

### Mise à jour Diagrammes
```bash
# 1. Éditer le fichier Mermaid
vim docs/diagrams/architecture.mmd

# 2. Générer
npm run docs:generate-diagrams

# 3. Vérifier
npm run docs:serve

# 4. Commit
git add docs/diagrams/
git commit -m "docs: update architecture diagram"
```

### Ajout Nouveaux Tests
```bash
# 1. Créer fichier test
touch e2e/accounting/new-feature.spec.js

# 2. Écrire tests
# 3. Exécuter
npm run e2e:accounting

# 4. Vérifier rapport
npm run e2e:report
```

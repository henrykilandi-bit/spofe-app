✅ KEY FEATURES

Append-Only Database
└─ PostgreSQL triggers prevent UPDATE/DELETE
   Historical data never lost
   Complete audit trail maintained

Atomic Transactions
└─ All 4 INSERTs (decision, events, facts, audit) atomic
   Automatic rollback on error
   ACID compliance guaranteed

Guardian Validation
└─ Checked BEFORE database write
   Process existence verified
   Actor role permission validated
   Checksum generated for immutability

Mandatory Audit
└─ Every decision logged
   Guardian checksum embedded
   Traceability guaranteed
   Immutable records

Enterprise Security
└─ Parameterized queries (SQL injection prevention)
   Transaction isolation enforced
   Role-based access control
   Error handling (no data leaks)

🎯 CORE SYSTEM ARCHITECTURE

HTTP Request
    ↓
TransactionManager (Orchestrator)
    ├→ Guardian validates (BEFORE DB write)
    ├→ PostgreSQL BEGIN
    ├→ INSERT decision
    ├→ INSERT events
    ├→ INSERT facts
    ├→ INSERT audit_log (MANDATORY LAST)
    └→ PostgreSQL COMMIT or ROLLBACK
    ↓
HTTP Response (201 | 400 | 403 | 500)
